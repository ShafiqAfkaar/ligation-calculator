How the ratio is calculated. Molar amount is taken as proportional to length in base pairs, which is the usual bench approximation. It ignores GC-content and end-modification effects on true molecular weight — fine for setting up a cloning reaction, not a substitute for a spectrophotometric molarity measurement.

Why 0.5 µL matters. Air-displacement pipettes lose accuracy fast below about 0.5 µL. Vector and insert are checked separately, so if both are too small you are told about both.

Your data stays here. The calculation runs entirely in your browser. Nothing you type is transmitted, stored, or logged — there is no analytics and no server. The page does request its typefaces from Google Fonts, which like any web font sees your IP address; that is the only outbound request, and the page works without it.
